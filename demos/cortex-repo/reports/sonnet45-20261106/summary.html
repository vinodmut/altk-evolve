What Evolve learned

From the training session (training: 3 traps hit, 40 tool calls, passed). Promoted unchanged:

  • For code generation systems, always modify the source schema first, then run the generation tool, rather than manually editing generated files
  • When commit hooks reject a commit, read the error message to identify all required companion changes (changelog, version bumps, commit format) before re-attempting
  • For schema changes that add database columns, use the repository's migration tool to auto-generate the migration rather than writing SQL manually
  • After making changes to a schema-driven system, run the repository's consistency check tool before committing to catch mismatches between schema and derived artifacts

Not promoted:

  • For repositories with semantic versioning requirements, determine the version bump type (major/minor/patch) based on the nature of the change before modifying VERSION files
