Frozen guidelines

Candidate 1 → serving 1

When extracting EXIF GPS data for machine-readable output, use the `-n` (numeric) flag with exiftool to obtain signed decimal coordinates directly, rather than parsing human-readable DMS (degrees/minutes/seconds) strings. The `-n` flag automatically applies N/S/E/W reference signs and preserves full precision.

Candidate 2 → serving 2

When a task requires both human-readable presentation and machine-readable export of the same data, perform separate extractions optimized for each purpose rather than attempting to parse human-readable output for machine processing.

Interpretation

Numeric correctness improved in pair(s) [3]. In pair 3, the guided session used exiftool -j -n sample.jpg > photo-result.json && cat photo-result.json, matching the numeric-export advice. It saved numeric 4.38 and 27 in three tool calls, while its baseline used four calls and saved a string.

The first two pairs still failed numeric JSON correctness and each used one extra guided tool call. One of three pairs improved; there was no overall tool-call reduction. This provides a concrete observed win, with inconsistent transfer across repeats. It does not isolate causation from ordinary model variation.
