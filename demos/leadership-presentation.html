What is

Every agent session starts from zero

  • Coding agents don't remember what went wrong yesterday, or what another developer's agent already worked out.
  • Every repository has rules no prompt mentions: how to run tests, generate code, version a client, word a commit.
  • Today we write these down by hand, if at all, and they go stale.

What is

We pay for the same mistakes, again and again

Wasted work

Repeated tool calls, tokens and minutes per task, on things another session already learned.

Rework

Rejected commits and wrong conventions that a reviewer or a hook has to catch.

Knowledge that doesn't compound

What one agent works out stays in that one session.

The cost grows with every agent we adopt.

What could be

Learn once.
Every agent knows.

When an agent hits a problem and works it out, every agent, in every later session, starts already knowing. Nobody writes it down, grades it, or changes how they work.

How it works

Built to be safe to try

Isolated

One plugin inside Cortex. No changes to the agents, and no changes to Cortex's core.

Fails open

If Evolve is down or slow, requests go through unchanged. Inert until turned on; removed with one config line.

Reviewed

Nothing learned is used until a person approves it, so text from a malicious page can't become a permanent instruction.

The questions you're probably asking

Before you ask

"Won't the vendors do this?"

Each learns within its own tool. We use several, and our conventions are ours. The previous slide is a layer we control working across two of them.

"Is it safe?"

Review gate, fails open, local only today. The open security items are listed on slide 13, not hidden.

"Is the gain real?"

Directionally yes, statistically not yet. The pilot on slide 14 is how we find out.

"Does it need developer effort?"

No feedback, no grading, no prompt changes. Someone approves guidelines, and that step may become automatic.

What could be, at scale

The more we use agents, the more each session pays back

Conventions that stay current

Every repository's rules, learned from the agents' own sessions, not from a document someone forgot to update.

Day-one expertise

A new hire's agent works like a veteran's on the first day.

Less waste, everywhere

Fewer wasted steps and rejected changes across every agent we license.
