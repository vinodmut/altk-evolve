# Revenue reconciliation after the Cortex upstream merge

Cortex `evolve-plugin` now includes public upstream `8b0facd5`, merged as
`4262d0a8`. The merge was conflict-free. Its source tree exactly matches the
previously tested scratch merge, and the full-profile binary includes Evolve.
The everyday Cortex service and configuration were not replaced.

## Does Cortex record tools?

Yes. In the recorded training session, Cortex supplied 17 Bash calls and 17
matching tool outputs to Evolve. The important gap was downstream: Evolve's
standard and fast-consistency prompt renderer included assistant text and
function calls but omitted tool-role observations. The accurate renderer also
omitted them from its extraction prompt, although resampling could use them.

The renderer now keeps each tool output with the matching action, including
errors, and reserves space for it when command arguments are long. Parallel
results are matched by call ID, without changing action indices. The accounting
contract is absent from the original rendered training input and present after
the fix. See [the recording audit](artifacts-postmerge/recording-audit.json),
[original rendering](artifacts-postmerge/original-learning-rendered.txt), and
[fixed rendering](artifacts-postmerge/learning-train-ledger-standard-correctness.rendered.txt).

These are bounded excerpts: Cortex sync retains up to 4,000 characters per tool
result; standard/fast rendering shares the configured 2,000-character step
payload budget between an action and its observation. Old processed batches and
existing guidelines are not automatically regenerated by this fix.

## The task and learning split

The agent must reconcile a month's revenue for a production customer, save
`report.json`, and return the same data. The service supplies the accounting
contract and raw ledger. Both comparison arms have exactly the same files,
tools, model, prompt, and 240-second/$1 limits.

The ledger contains corrections followed by stale replays, events subsequently
voided or moved to another month, sandbox-account rows, timestamps with offsets,
positive-magnitude refunds, and separate currencies. The grader independently
checks exact totals, included IDs, and the actual saved file.

Training uses Northwind Studio only. The initial run calculated the right answer
but did not save the report; feedback caused the agent to save and verify it.
Standard processing of the failed attempt learned that reconciliation and report
creation must be performed in code when there is no all-in-one CLI command.
Fast-consistency processing of the recovery also learned command discovery and
the importance of applying contract clauses in order.

Candidates `1`, `2`, and `4` were reviewed and promoted unchanged before any
held-out evaluation. Candidate `3`, about broadening search terms, was not used.
The six fresh account/month combinations and alternating arm order were frozen
in [comparison-plan.json](artifacts-postmerge/comparison-plan.json). No evaluated
case was used for learning, and automatic idle learning stayed disabled.

Both arms use the verified gateway bridge. It preserves all Cortex-injected
Anthropic system text in one string because this gateway otherwise ignores later
system-array blocks. See the [earlier diagnostic and readback](README.md#a-gateway-compatibility-problem).

## Results

On the six predeclared inputs, **Evolve passed 4/6 and the baseline passed 2/6**.
The three paired wins were Maple Workshop, Orchid Analytics, and Cedar Design.
Both arms failed Harbor Systems; Summit Labs regressed with guidance; both arms
passed Willow Works. The complete comparison is recorded in
[summary.json](artifacts-postmerge/summary.json). Every failure is retained.

| Customer | Baseline | Evolve | Turns: baseline / Evolve | Rejected service calls: baseline / Evolve |
|---|---|---|---:|---:|
| Maple Workshop | Fail | Pass | 16 / 12 | 7 / 1 |
| Orchid Analytics | Fail | Pass | 9 / 13 | 3 / 2 |
| Cedar Design | Timeout | Pass | 45 partial / 15 | 3 / 2 |
| Harbor Systems | Fail | Fail | 21 / 11 | 1 / 2 |
| Summit Labs | Pass | Fail | 13 / 14 | 4 / 2 |
| Willow Works | Pass | Pass | 20 / 20 | 5 / 6 |

Totals were 124 observed baseline turns versus 85 guided turns, and 23 rejected
service calls versus 15. The baseline turn total includes the timeout's partial
transcript. There is no claim of billing savings; its token/cost data is incomplete.

### First held-out example: Maple Workshop

The baseline reported USD **121,079 minor units**, whereas the independently
correct value is **12,502**. It included an event whose latest revision moved
outside the reporting month and selected the wrong UTC boundary events. The
guided run consulted command-specific help, executed Python to collapse revisions
before filtering, computed net revenue by currency, and saved the correct report.
Rejected API calls fell from seven to one; turns fell from 16 to 12.

This was the first input in the frozen plan. Its complete comparison, guideline
content, and first-request injection evidence are in
[example-ledger-a.json](artifacts-postmerge/example-ledger-a.json). All six guided
cases received the same three guideline IDs on their first request; no baseline
received them.

The failed guided cases show the limitation. Harbor Systems wrote arithmetic
expressions into JSON instead of calculating them. Summit Labs attempted a
one-line Python command whose comment swallowed the rest of the program, then
returned incorrect results. The learned coding procedure helped several runs,
but did not ensure that every run implemented it correctly.

The Cedar Design baseline hit the shared 240-second limit. It is retained as a
failure rather than retried or removed. The original driver did not persist
partial stdout on timeout, so this trial's partial transcript was recovered from
its Claude project log and paired with the actual Cortex session evidence.
The driver now preserves partial output on timeout. Token usage and cost are
unknown for that attempt; its turn count is the observed partial assistant count.

This is a small controlled comparison on synthetic data, not a general benchmark.
It does not isolate the renderer fix's causal contribution: the comparison tests
the frozen guidelines against no guideline injection. The before/after recording
audit independently establishes that the tool-output loss has been fixed.

## Walkthrough

To check the recorded example without making model calls or starting services:

```bash
uv run --no-sync python -m experiments.cortex_workflow_learning.run \
  --artifacts-dir experiments/cortex_workflow_learning/artifacts-postmerge verify
```

Prerequisites are the existing `uv` environment, `claude` CLI, the merged sibling
`../cortex/bin/cortex`, the trusted development Cortex CA, and the sandbox model
credential file configured by the driver. Ports 47800–47804 and 18201–18202 must
be free. Credentials remain in subprocess environments and are not saved in the
artifacts.

From the repository root, choose a new results directory:

```bash
export WORKFLOW_RESULTS=/private/tmp/cortex-revenue-fresh
workflow() {
  env UV_CACHE_DIR=/private/tmp/rossocortex-uv-cache \
    uv run --no-sync python -u -m experiments.cortex_workflow_learning.run \
    --artifacts-dir "$WORKFLOW_RESULTS" "$@"
}

workflow preflight
workflow start
workflow bridge-start
workflow trial --label train-ledger --case ledger_train --arm training --via-bridge
workflow learn --label train-ledger --mode standard --objective correctness
workflow feedback --label train-ledger --via-bridge
workflow learn --label train-ledger --mode consistency --objective correctness
workflow candidates
```

Inspect the candidates' content and source session. Generation varies: a fresh
successful training run may legitimately generate no corrective instruction.
For the recorded run, the reviewed candidate IDs were `1 2 4`; select the IDs
appropriate to the fresh training output before evaluation.

```bash
workflow promote --ids 1 2 4
workflow warm
workflow compare
workflow stop
```

`compare` freezes the selected guidelines and cases, alternates arm order,
disables learning, and writes a summary. If interrupted between completed
trials, rerunning the same command resumes the frozen plan without rerunning
completed trials. It rejects changes to the selected guidelines or cases.

Inspect `summary.json`, `comparison-plan.json`, each trial's
`initial.metrics.json`, actual `report.json`, and transcript. Baselines must have
no injected IDs; every guided case must have the frozen IDs on the first model
request. Compare correctness separately from turns, service errors, and cost.

To run the relevant checks:

```bash
uv run pytest -v tests/unit/test_guidelines.py tests/unit/test_consistency_guidelines.py tests/unit/test_cortex_sync.py
uv run pytest -v -m e2e tests/e2e/test_cortex_loop.py
uv run pytest -v experiments/cortex_workflow_learning/test_workflows.py experiments/cortex_learning_demo/test_demo.py
```
