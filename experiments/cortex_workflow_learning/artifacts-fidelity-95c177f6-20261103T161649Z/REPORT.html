Task and accounting rules

The agent reconciles a specified month for a customer's production account using a local billing CLI, saves a report, and returns matching JSON. The raw export contains 15 ledger rows, including sandbox accounts, corrected events followed by stale replays, voided events, and events moved to another month. Refund amounts are positive magnitudes, and USD and EUR must stay separate.

  1. Discover the supported commands and resolve the production account.
  2. Read the accounting contract and download the raw ledger.
  3. Keep the greatest numeric revision per event across the entire export before filtering.
  4. Filter production account, settled status, and the UTC half-open monthly interval. Parse timezone offsets.
  5. Add captures and subtract refunds within each currency; sort the included event IDs.
  6. Save exact integer totals and event IDs in report.json, then return that same JSON.
