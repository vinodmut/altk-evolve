Billing benchmark walkthrough

A photo task you can run yourself in Claude Code

Use the photo-metadata example from Evolve's linked Claude Code video: work out where a photo was taken from EXIF, then reuse the working approach to answer a focal-length question in a fresh session.

This adaptation uses full Evolve with Cortex capture, explicit reflection, review, promotion, and proxy injection. The current website starter example uses Evolve Lite and Claude native memory; its plugin commands are a different learning route.

You run normal interactive Claude Code. You type the tasks, watch and approve tool calls, inspect answers, and exit each session yourself. The service helper manages the local processes. All agent tasks below are interactive.

  1. Run a focal-length baseline with injection off.
  2. Run and verify a separate GPS task; Evolve learns its successful extraction procedure.
  3. Review and promote generated guidelines.
  4. Repeat the identical focal-length prompt in a fresh session and inspect the injected guidelines and actual tool behavior.

The useful behavior to look for is reuse of a verified local EXIF command or interpreter environment, with fewer failed or exploratory commands and correct tag interpretation. The guide preserves whatever actually happens. A model with an available EXIF tool may solve both attempts equally well.

1

Gather the prerequisites

You need a matching Cortex build with the Evolve plugin, uv, git, make, go, a C/C++ compiler for the Cortex build, openssl, curl, jq, and a recent claude CLI.

This guide uses the integration branches: Evolve: vinodmut/kaizen, branch rossocortex and Cortex: vinodmut/cortex, branch evolve-plugin. Evolve is installed directly from Git into uv’s managed cache. Only Cortex is cloned and built: this fork’s evolve-plugin branch has no downloadable release binary, and its local Go module replacements prevent a simple versioned go install. No existing checkout or path editing is needed.

Photo-task requirement for the recorded example: exiftool must be installed and available on the shell's PATH. The full development check ran on macOS with ExifTool installed. The photo task itself also works on other platforms that provide ExifTool. A Pillow-based Python extractor can perform the task, but its commands and generated guidelines will differ from the recorded ExifTool example.

On macOS with Homebrew, install ExifTool if it is missing:

brew install exiftool

Verify that the terminal can find it before continuing. The same installed tools remain available during baseline, training, and guided sessions.

Evolve requires Python 3.12 or later; uv run --no-project --with creates a cached environment and downloads Python 3.12 if needed. Use the Go toolchain required by the Cortex checkout’s cmd/cortex/go.mod (1.26.10 in the checked snapshot). The recorded rerun used Claude Code 2.1.287.

Gateway requirementThis setup expects one gateway and credential that support Anthropic /v1/messages, OpenAI-compatible /v1/chat/completions, and a model catalog at /v1/models or /models. 5

Prepare the Cortex CA and configure the LLM gateway

Cortex requires a signing certificate, private key, and trust certificate named tls.crt, tls.key, and ca.crt. If you chose an existing Cortex CA, check that all three exist and skip the generation block.

For a new demo CA directory only:

mkdir -p "$DEMO_CA_DIR"
chmod 700 "$DEMO_CA_DIR"
if [ -e "$DEMO_CA_DIR/tls.key" ] || [ -e "$DEMO_CA_DIR/tls.crt" ]; then
  printf 'A CA already exists here; reuse it or choose a new DEMO_CA_DIR.\n'
else
  cat > "$DEMO_CA_DIR/ca.cnf" <<'CA_CONFIG'
[req]
prompt = no
distinguished_name = dn
x509_extensions = v3_ca
[dn]
CN = Cortex Evolve Manual Demo CA
[v3_ca]
basicConstraints = critical,CA:TRUE
keyUsage = critical,keyCertSign,cRLSign
CA_CONFIG
  openssl req -x509 -newkey rsa:2048 -nodes -sha256 -days 30 \
    -config "$DEMO_CA_DIR/ca.cnf" \
    -keyout "$DEMO_CA_DIR/tls.key" -out "$DEMO_CA_DIR/tls.crt"
  cp "$DEMO_CA_DIR/tls.crt" "$DEMO_CA_DIR/ca.crt"
  chmod 600 "$DEMO_CA_DIR/tls.key"
fi
test -f "$DEMO_CA_DIR/tls.key"
test -f "$DEMO_CA_DIR/tls.crt"
openssl x509 -in "$DEMO_CA_DIR/ca.crt" -noout -subject
You should seeOpenSSL may print key-generation progress, then the certificate subject. A newly generated CA has subject Cortex Evolve Manual Demo CA. An existing CA has its own subject. The interactive launcher configures the agent’s NODE_EXTRA_CA_CERTS for this CA; installing it into the OS trust store is unnecessary for this demo.

Configure the gateway used by Evolve and the task agent

Evolve needs an LLM to generate, reconcile, and retrieve guidelines. In this demo, it calls your gateway’s OpenAI-compatible API; Claude Code calls the same gateway’s Anthropic-compatible API. Cortex’s proxy/MCP addresses are separate from this LLM endpoint.

Define the service helper

Paste the entire block into the same Bash or zsh terminal. It writes a standalone helper to $DEMO_ROOT/services.py and defines the services command. The helper uses your temporary paths and dedicated photo namespaces; it does not import any repository-only experiment code. It manages setup, the injection toggle, cleanup, and the configured interactive Claude launch. You launch Claude Code and enter every task prompt yourself.

cat > "$DEMO_ROOT/services.py" <<'SERVICES_PY'
"""Standalone process setup for the interactive photo walkthrough."""

import argparse
import json
import os
import signal
import subprocess
import time
from datetime import datetime, timezone
from pathlib import Path

import httpx
import yaml
from dotenv import dotenv_values

ROOT = Path(os.environ["DEMO_ROOT"])
RESULTS = Path(os.environ["DEMO_RESULTS"])
RUNTIME = RESULTS / "runtime"
STATE = RESULTS / "state.json"
API = "http://127.0.0.1:47801"
MCP = "http://127.0.0.1:18201/sse"


def load_state():
    return json.loads(STATE.read_text())


def save_state(state):
    RESULTS.mkdir(parents=True, exist_ok=True)
    STATE.write_text(json.dumps(state, indent=2) + "\n")


def environment(model=None):
    values = {k: v for k, v in dotenv_values(os.environ["DEMO_CREDENTIALS"]).items() if v}
    token = values.get("ANTHROPIC_API_KEY") or values.get("ANTHROPIC_AUTH_TOKEN")
    if not token or not values.get("ANTHROPIC_BASE_URL"):
        raise RuntimeError("Complete the gateway URL/key setup before preflight.")
    base = values["ANTHROPIC_BASE_URL"].rstrip("/")
    if base.endswith("/v1"):
        base = base[:-3]
    env = os.environ.copy()
    for name in ("HTTP_PROXY", "HTTPS_PROXY", "ALL_PROXY", "http_proxy", "https_proxy", "all_proxy"):
        env.pop(name, None)
    env.update(values)
    env.pop("ANTHROPIC_AUTH_TOKEN", None)
    selected = model or env.get("EVOLVE_MODEL_NAME", "Azure/gpt-4.1")
    env.update(
        ANTHROPIC_BASE_URL=base,
        ANTHROPIC_API_KEY=token,
        OPENAI_BASE_URL=base + "/v1",
        OPENAI_API_KEY=token,
        EVOLVE_CUSTOM_LLM_PROVIDER="openai",
        EVOLVE_MODEL_NAME=selected,
        EVOLVE_GUIDELINES_MODEL=selected,
        EVOLVE_BACKEND="filesystem",
        EVOLVE_DATA_DIR=str(RUNTIME / "data"),
        EVOLVE_SQLITE_PATH=str(RUNTIME / "entities.sqlite.db"),
        EVOLVE_NAMESPACE_ID="photo-reviewed",
        EVOLVE_GUIDELINES_MODE="consistency",
        EVOLVE_INJECTION_MODE="retrieval",
        EVOLVE_OTEL_ENABLED="false",
        EVOLVE_RETENTION_SCHEDULER_ENABLED="false",
        EVOLVE_HOOKS_CONFIG="",
    )
    return env


def uv_command(*args):
    return ["uv", "run", "--no-project", "--python", "3.12", "--with", os.environ["DEMO_EVOLVE_SPEC"], *args]


def preflight():
    if STATE.exists():
        raise RuntimeError("A run already exists. Choose a fresh DEMO_RESULTS directory.")
    binary = Path(os.environ["DEMO_CORTEX_BIN"])
    ca = Path(os.environ["DEMO_CA_DIR"])
    if not binary.is_file() or not os.access(binary, os.X_OK) or not all((ca / n).is_file() for n in ("ca.crt", "tls.crt", "tls.key")):
        raise RuntimeError("Complete the Cortex build and CA setup before preflight.")
    env = environment()
    catalog = []
    with httpx.Client(trust_env=False, timeout=25) as client:
        for path in ("/v1/models", "/models"):
            response = client.get(env["ANTHROPIC_BASE_URL"] + path, headers={"Authorization": "Bearer " + env["OPENAI_API_KEY"]})
            if response.status_code == 200:
                catalog = [m["id"] for m in response.json().get("data", [])]
                break
    preferred = ["Azure/gpt-4.1", "gpt-4.1", "claude-sonnet-4-5"]
    model = next((m for m in preferred if m in catalog), None)
    model = model or next((m for m in catalog if "gpt-4.1" in m.lower() and "mini" not in m.lower()), None)
    if not model:
        raise RuntimeError("No supported task model was found in the gateway catalog.")
    save_state({"created_at": datetime.now(timezone.utc).isoformat(), "model": model, "services": {}})
    print(json.dumps({"model": model, "task": "Read embedded EXIF metadata from a local photo."}))


def cortex_config():

        "mode": "proxy-sidecar",
        "listener": {
            "roles": ["forward"],
            "bind_loopback_only": True,
            "forward_proxy_addr": "127.0.0.1:47800",

            "transparent_proxy_addr": "127.0.0.1:47803",
            "health_addr": "127.0.0.1:47804",
        },
        "stats": {"address": "127.0.0.1:47802"},
        "tls_bridge": {"mode": "enabled", "ca_dir": os.environ["DEMO_CA_DIR"], "generate_ca": False},
        "cost_ledger": {"enabled": False},
        "pipeline": {
            "outbound": {
                "plugins": [
                    {"name": "inference-parser"},
                    {"name": "mcp-parser"},
                    {"name": "a2a-parser"},
                    {
                        "name": "evolve",
                        "config": {
                            "endpoint": MCP,
                            "agents": ["claude-code"],
                            "serve_namespace": "photo-reviewed",
                            "learn_namespace": "photo-candidates",
                            "processing_profile": "photo-demo",
                            "learn": False,
                            "inject": False,
                            "idle_after_seconds": 60,
                            "cache_ttl_seconds": 30,
                            "timeout_ms": 15000,
                            "learn_timeout_seconds": 180,
                        },
                    },

            }

def spawn(name, command, state, env):
    RUNTIME.mkdir(parents=True, exist_ok=True)
    with (RUNTIME / f"{name}.log").open("w") as log:
        child = subprocess.Popen(command, cwd=ROOT, env=env, stdin=subprocess.DEVNULL, stdout=log, stderr=log, start_new_session=True)
    state["services"][name] = {"pid": child.pid, "command": command}
    save_state(state)
    return child


def start():
    state = load_state()
    if state["services"]:
        raise RuntimeError("Services have already been started for this run.")
    RUNTIME.mkdir(parents=True, exist_ok=True)
    config = RUNTIME / "cortex.yaml"
    config.write_text(yaml.safe_dump(cortex_config(), sort_keys=False))
    env = environment(state["model"])
    children = [
        spawn("evolve", uv_command("evolve-mcp", "--transport", "sse", "--port", "18201"), state, env),
        spawn("cortex", [os.environ["DEMO_CORTEX_BIN"], "--config", str(config)], state, env),
    ]
    with httpx.Client(trust_env=False, timeout=2) as client:
        for _ in range(60):
            if any(c.poll() is not None for c in children):
                raise RuntimeError("A service exited. Inspect runtime/cortex.log and runtime/evolve.log; use services stop to clean up.")
            try:
                response = client.get(API + "/v1/pipeline")
                with client.stream("GET", MCP) as stream:
                    if response.status_code == stream.status_code == 200:
                        names = [p["name"] for p in response.json()["outbound"]]
                        if "evolve" in names:
                            print(json.dumps({"started": ["evolve", "cortex"], "pipeline": names}))
                            return
            except httpx.HTTPError:
                pass
            time.sleep(1)
    raise RuntimeError("Services were not ready within 60 seconds. Inspect the runtime logs and use services stop.")


def bridge_start():
    state = load_state()
    if "bridge" in state["services"]:
        raise RuntimeError("The bridge is already running for this run.")
    env = environment(state["model"])
    env["WORKFLOW_REAL_GATEWAY"] = env["ANTHROPIC_BASE_URL"]
    child = spawn("bridge", uv_command("python", str(Path(__file__).resolve()), "bridge"), state, env)
    with httpx.Client(trust_env=False, timeout=1) as client:
        for _ in range(30):
            if child.poll() is not None:
                raise RuntimeError("The bridge exited. Inspect runtime/bridge.log.")
            try:
                if client.get("http://127.0.0.1:18202/openapi.json").status_code == 200:
                    print(json.dumps({"started": "bridge", "port": 18202}))
                    return
            except httpx.HTTPError:
                pass
            time.sleep(1)
    raise RuntimeError("Bridge startup timed out. Inspect runtime/bridge.log.")


def injection(enabled):
    path = RUNTIME / "cortex.yaml"
    config = yaml.safe_load(path.read_text())
    plugin = next(p for p in config["pipeline"]["outbound"]["plugins"] if p["name"] == "evolve")
    if plugin["config"]["learn"]:
        raise RuntimeError("Automatic learning must remain off.")
    plugin["config"]["inject"] = enabled
    path.write_text(yaml.safe_dump(config, sort_keys=False))
    time.sleep(3)
    print(json.dumps({"inject": enabled, "learn": False}))


def stop():
    state = load_state()
    for service in state["services"].values():
        try:
            os.killpg(service["pid"], signal.SIGTERM)
        except ProcessLookupError:
            pass
    print("Stopped only the processes recorded for this demo.")

def serve_bridge():
    from fastapi import FastAPI, Request
    from starlette.responses import StreamingResponse
    import uvicorn

    app = FastAPI()
    hop = {"host", "content-length", "connection", "transfer-encoding", "content-encoding"}

    @app.post("/v1/messages")
    async def messages(request: Request):
        body = await request.json()
        system = body.get("system")
        if isinstance(system, list):
            if any(not isinstance(b, dict) or b.get("type") != "text" or not isinstance(b.get("text"), str) for b in system):
                raise ValueError("The bridge supports text system blocks only.")
            body = {**body, "system": "\n\n".join(b["text"] for b in system)}
        headers = {k: v for k, v in request.headers.items() if k.lower() not in hop}
        client = httpx.AsyncClient(trust_env=False, timeout=180)
        upstream = client.build_request(
            "POST", os.environ["WORKFLOW_REAL_GATEWAY"].rstrip("/") + "/v1/messages", headers=headers, json=body
        )
        try:
            response = await client.send(upstream, stream=True)
        except BaseException:
            await client.aclose()
            raise

        async def stream():
            try:
                async for chunk in response.aiter_bytes():
                    yield chunk
            finally:
                await response.aclose()
                await client.aclose()

        returned = {k: v for k, v in response.headers.items() if k.lower() not in hop}
        return StreamingResponse(stream(), status_code=response.status_code, headers=returned)

    uvicorn.run(app, host="127.0.0.1", port=18202, log_level="warning", access_log=False)
